# 📚 LMS – Learning Management System (MERN Stack)

A full-stack Learning Management System built using **MongoDB, Express.js, React.js, and Node.js**.  
This project includes **Frontend**, **Admin Dashboard**, and **Backend API** in a single repository.

---

## 🚀 Features

### 🧑‍🎓 Student Side (Frontend)
- User login/signup  
- View available courses
- Buy the course 
- Enroll in courses  
- Watch course videos  
- Track progress  

### 🛠 Admin Dashboard
- Admin authentication  
- Add/Edit/Delete courses  
- Upload videos
- Bookings
- Manage users  
- Check analytics(Total Booking, Revenue)  
- Course performance 

### ⚙️ Backend (Node + Express)
- Secure Authentication (JWT)  
- MongoDB Database models  
- API for courses, users, categories  
- Video uploads
- Protected routes

| Layer | Technology |
|-------|-------------|

| Database | MongoDB |
| Authentication | JWT, bcrypt |
| File Uploads | Multer / Cloud storage |

#### Backend:

#### Backend:

## 🔐 Environment Variables (.env)

Add `.env` file in Backend:

MONGO_URI=your_mongo_db_url
JWT_SECRET=your_jwt_secret
PORT=5000
CLOUD_KEY=your_cloud_key
CLOUD_SECRET=your_cloud_secret
